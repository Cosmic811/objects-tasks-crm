# Объекты и задачи: обновление интерфейса

Дата проверки: 6 ноября 2026 года. Ветка: `design-refinement`.

Подготовлена отдельная версия существующей CRM в направлении Architectural Workspace. Опубликованный сайт и ветка `main` не обновлялись. Локальный preview доступен по адресу [127.0.0.1:5173](http://127.0.0.1:5173/), пока работает сервер разработки. Это локальный адрес, его нельзя отправить работодателю как публичную демоверсию.

## Что изменено

| Область | До обновления | После обновления |
| --- | --- | --- |
| Вход | Компактная стандартная форма | Двухчастная композиция на desktop, короткая форма на телефоне, показ/скрытие пароля |
| Навигация | Светлая боковая панель | Тёмная панель с контекстом, ролью, именем пользователя и явным выходом; выдвижное меню на телефоне |
| Объекты | Простой список | Название и адрес ведут строку, реальные счётчики отделены, вся строка остаётся ссылкой |
| Задачи объекта | Таблица, на телефоне меньше данных | Семантическая таблица на desktop и отдельные мобильные карточки с исполнителем, статусом и подсказкой следующего действия |
| Задача | Метаданные конкурировали с работой | Сначала описание, причина возврата и разрешённое действие; на телефоне метаданные идут ниже |
| История | Компактный перечень записей | Хронологическая шкала: предыдущий/новый статус, автор, время и настоящий комментарий |
| Обновление статуса | Загрузка могла заменять всю карточку | Загруженные данные остаются видимыми до ответа; действия заблокированы до завершения обновления |
| Формы | Разрозненные визуальные состояния | Общие поля, подписи, кнопки, ошибки, видимый фокус и нативные диалоги |

Палитра: тёмная навигация `#15242A`, текст `#17252B`, фон `#F3F2ED`, белые поверхности, действие `#1C756E`. Шрифт Manrope с кириллицей поставляется вместе с приложением. Иконки Lucide используются в одном начертании. Декоративная геометрия на входе не представляет реальный строительный объект и не содержит вымышленных показателей.

## Motion

| Событие | Поведение |
| --- | --- |
| Переход по маршруту | 200 мс, появление уже видимого содержимого и сдвиг на 5 px |
| Открытие диалога | 220 мс, сдвиг на 8 px и масштаб 0.985 → 1; затемнение 150 мс |
| Мобильное меню | Короткий сдвиг на 18 px из левого края |
| Статус и история | Появление 200 мс после ответа сервера; новые реальные события добавляются без замены карточки скелетоном |
| Наведение и нажатие | 150-200 мс, тон/граница/положение стрелки |
| Reduced motion | Анимации и переходы выключаются через `prefers-reduced-motion` |

Нет бесконечных анимаций, искусственных задержек запросов и отдельной библиотеки анимации. Короткая видеозапись не подготовлена; motion можно проверить в локальном preview.

На ширинах 360, 390, 768, 1024 и 1440 проверены вход, объекты, карточка объекта и задача. В 20 измерениях ширина документа не превысила доступную ширину окна. [Измерения адаптивности](qa/design/responsive.json). На телефоне таблица заменяется карточками без потери исполнителя. Диалог задачи отдельно проверен на 360 px. Проверены перенос длинного заголовка, доступность элементов клавиатурой, видимый фокус, Escape, возврат фокуса к открывшей кнопке и переход к началу содержимого при смене маршрута.

Ручной сценарий выполнен на настоящем Supabase через интерфейс двух ролей:

1. Постановщик создал отдельный проверочный объект и изменил адрес.
2. Создал задачу с длинным названием, назначил Ивана Петрова и изменил описание.
3. Исполнитель взял задачу в работу и отправил на проверку. Административные кнопки отсутствовали.
4. Постановщик проверил отказ для пустой причины возврата, затем вернул задачу с комментарием.
5. Исполнитель взял её на доработку и повторно отправил на проверку.
6. Постановщик принял работу. В истории отображались семь событий с правильными авторами и комментарием.
7. Проверочные задача и объект скрыты штатным мягким удалением. Исходные три объекта и пять задач сохранились.

Auth, API, правила переходов, типы данных и SQL не менялись: diff для `src/auth/`, `src/lib/`, `src/types/` и `supabase/` пуст. HashRouter, роли и существующие маршруты сохранены. Редизайн не подменяет Supabase локальными данными.

Ограничения проверки: один браузер Chromium, без отдельного прогона на физических устройствах, Safari и экранном дикторе. Reduced motion проверен по реализации CSS, отдельная системная эмуляция не выполнялась. Существующий API-набор не запускался повторно в этом этапе; вместо него дополнительно пройден реальный ручной цикл. Сборка выдаёт предупреждение о JS-файле около 526 КБ до gzip (около 152 КБ gzip), ошибок сборки нет. Автоматический дизайн-детектор недоступен из-за отсутствующего движка; его запуск не заявляется успешным.

Независимый финальный просмотр завершился с вердиктом `ship`, без существенных исправлений. Проверяющий просмотрел 24 снимка и исходники: desktop/phone-композицию, формы, длинное название, порядок чтения задачи, исполнителя, историю и контраст. Это проверка предоставленных экранов и кода, а не отдельный запуск сценариев в другом браузере.
